Chat

Chat is how parents plan with Giddy: they talk, Giddy shows what it checked, proposes a plan card, and offers quick replies.

WCAG 2.2 AAStatus: stable

Overview

Parent bubbles are grape on the right; Giddy’s are white cards on the left with the balloon avatar. While Giddy works, tool steps tick off live and typing dots bounce; the send button becomes Stop. Proposals arrive as a dashed plan card with prices and a single “Use this plan” primary.

Anatomy

  1. Parent bubbleAccent, right, tail bottom-right.
  2. Giddy avatarMascot.
  3. Tool stepsWhat Giddy checked.
  4. SuggestionsChips that send a reply.

Responsive behaviour

  • Composer sticks to the bottom, above the tab bar on phones.
  • From 1024px a “Party at a glance” aside sits beside the chat.

Theming

--bubble-me-bg/fg (accent), agent bubbles use card tokens; plan card uses accent subtle with a dashed accent border.

Accessibility

Role and pattern

Log is an <ol aria-live="polite">; new Giddy messages are announced once complete, tool steps as they finish.

Keyboard

KeyAction
EnterSends.
Shift+EnterNew line.
EscStops Giddy while thinking.
TabInto suggestions and plan actions.

Focus

Stays in the composer after sending.

Labelling

Composer: “Message Giddy”; Stop: “Stop Giddy”; typing dots: “Giddy is thinking”.

Motion

Typing dots bounce (--duration-loop); static with reduced motion.

Touch

Send/Stop 40px; suggestion chips 32px with 8px gaps.

Content

  • Giddy speaks warmly and briefly; numbers first (“keeps you $22 under budget”).
  • Giddy says what it checked before what it suggests.
  • Suggestions are written as the parent would reply.
