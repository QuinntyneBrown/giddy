Chip

Chips are round pills you tap: filters (“For Zuri (7)”), suggested replies to Giddy, removable memories.

WCAG 2.2 AAStatus: stable

Overview

Filter chips toggle with aria-pressed. Suggestion chips in chat send their text as a message. Input chips have a labelled remove button.

Anatomy

  1. Pill32px, strong border.
  2. LabelLabel text; selected turns accent.

Variants

Prefers venues with parking
Filter on/off, suggestion, removable.
HTML
<button class="chip" type="button" aria-pressed="true">For Zuri (7)</button><button class="chip" type="button" aria-pressed="false">Outdoor</button><button class="chip" type="button">Yes, add a GF pizza</button><span class="chip">Prefers venues with parking <button class="remove" type="button" aria-label="Forget: prefers venues with parking">×</button></span>

Sizes

Not applicable: One size (<code>--chip-height</code>).

States

VariantDefaultHoverFocusSelectedDisabled
Filter

Responsive behaviour

  • Chip rows wrap with .cluster.

Theming

Selected uses accent subtle + accent border.

Accessibility

Role and pattern

<button aria-pressed> for filters, inside role="group" with a label.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
Space / EnterToggle or send.

Focus

The shared ring (--focus-ring-width 2px of --color-focus-ring, 2px offset) appears on :focus-visible only.

Labelling

Remove buttons: “Forget: …”.

Contrast

Label
Selected
Edge

Motion

Colour and border changes use --duration-fast (120 ms) with --ease-standard; reduced motion zeroes the duration in the tokens, so nothing extra is needed.

Touch

32px chips with 12px gaps; remove 20px inside the chip.

Content

  • Filters are adjectives or facts: “Indoor”, “Under $200”.
  • Suggestions are the parent’s voice: “Yes, add a GF pizza”.
