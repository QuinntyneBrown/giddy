Bottom navigation

Under 1024px, a five-item tab bar sits at the bottom of the screen within thumb reach, with Ask Giddy raised in the middle.

WCAG 2.2 AAStatus: stable

Overview

Five destinations: Home, Explore, Ask Giddy, Parties, Family. The centre item is the agent: a raised grape circle on a press lip. Pages that use it add .has-bottom-nav to <body>, which pads main and lifts toasts, the chat composer and the cookie banner above it.

Anatomy

  1. Current itemIcon in an accent-subtle pill, accent label.
  2. ItemIcon + caption, 44px target.
  3. Agent buttonRaised accent circle with press lip.

Variants

One variant. Explore highlights for Themes, Venues and Fun & food; Parties highlights for every party page.

Sizes

Not applicable: Height is <code>--layout-bottom-nav-height</code> (72px) plus the safe area.

Responsive behaviour

  • Shown below 1024px, hidden above.
  • Adds env(safe-area-inset-bottom) on notched phones.

Theming

Surface background, --shadow-3 upwards; agent button uses accent + --shadow-press.
