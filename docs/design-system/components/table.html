Table

Tables line up comparable data: guests with RSVP and allergies, budget lines, venue comparisons.

Overview

Use when people compare across rows or columns. Tables scroll inside .table-wrap on phones. Row actions appear on hover/focus and are always visible on touch. Selectable tables put a checkbox first and show a bulk bar.

Anatomy

  1. HeaderSunken background, sortable headers use aria-sort.
  2. Row12×16px cells, hover tint.
  3. Numeric columnRight-aligned, tabular numbers.
  4. Frame.table-wrap: border, radius, horizontal scroll.

Responsive behaviour

  • Scrolls horizontally inside its frame under 768px; the page never scrolls sideways.
  • Row actions always visible on (hover: none).
  • The compare table keeps the feature column readable as the first column.

Theming

Header --color-bg-surface-sunken (cream-100 / night-990), hover --color-bg-subtle, selected --color-accent-subtle.

Accessibility

Role and pattern

Native <table> with <caption> (may be visually hidden) and scope.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
EnterActivates a sort header or row action.

Focus

The shared ring (--focus-ring-width 2px of --color-focus-ring, 2px offset) appears on :focus-visible only. Rows with :focus-within reveal their actions.

Labelling

Row checkboxes: “Select Maya Chen”. Icon actions: “Remove Maya Chen”.

Content

  • Column headers are short nouns.
  • Money with $ and no decimals unless needed.
