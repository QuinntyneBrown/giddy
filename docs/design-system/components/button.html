Button

Buttons let parents take an action: plan, book, send, save. The grape primary button with its chunky “pressable” lip marks the one thing that matters most on a screen.

WCAG 2.2 AAStatus: stableNative <button>

Overview

Use a button when activating it changes something: it submits, books, sends, deletes or opens a dialog. Use a link when it only goes somewhere. Giddy buttons are pill-shaped and bold so small hands and busy parents can hit them; the primary sits on a 4px lip (--shadow-press) that collapses when pressed, which makes the tap feel physical.

  • Primary: the one action the view exists for (“Plan a party”, “Book 1:00–3:30 pm”, “Send to 16 families”). Never two per view.
  • Secondary (default look): every other action.
  • Ghost: dense places such as table rows, card headers and the top bar.
  • Link: low-emphasis actions inside sentences (“send it again”).
  • Danger: destructive confirmations only (“Delete party”, “Remove Ethan”).

Anatomy

  1. Leading icon (optional)1.25em, inherits the label colour, aria-hidden.
  2. LabelVerb phrase in sentence case; the accessible name.
  3. ContainerPill (--radius-full), height from --control-height-*, 1px border.
  4. Press lip (primary)--shadow-press: 4px of --color-accent-press; removed on :active.

Variants

Emphasis from highest to lowest; danger only inside a confirmation.

Both themes

  • Active on primary drops the button 4px onto its lip; secondary moves 1px.
  • Loading keeps the width, hides the label, spins, sets aria-busy and ignores further clicks.
  • Pressed (toggle) uses aria-pressed; filters use chips instead.

Responsive behaviour

  • Below 768px, the primary action of an auth card, RSVP form or dialog sheet is full width (.btn--block).
  • Dialog footers wrap; the primary stays last.
  • Medium and large meet the 44px comfortable target with the lip; small (32px) only appears inside tappable rows.
  • Labels never truncate; shorten the verb phrase instead.

Theming

Each variant sets four component tokens (--btn-bg, --btn-fg, --btn-border, --btn-bg-hover) from semantic tokens. In dark mode the accent lightens to grape-300 and the label flips to grape-950 (7.9:1); the press lip uses --color-accent-press, which becomes grape-500 so it still reads on the night canvas. Inside .hero the primary inverts to a white pill with grape text.

Accessibility

Role and pattern

Native <button> (type="submit" in forms). Links styled as buttons stay <a href>.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
Enter, SpaceActivates. Space fires on key up so a mis-press can be cancelled.

Focus

The shared ring (--focus-ring-width 2px of --color-focus-ring, 2px offset) appears on :focus-visible only. On primary the 2px offset shows the surface, keeping the ring ≥ 3:1 against both.

Labelling

The visible label is the name. Icon-only buttons need aria-label with the verb and object (“Save Dino Den to favourites”). Busy buttons keep their name and add aria-busy.

Motion

Colour and border changes use --duration-fast (120 ms) with --ease-standard; reduced motion zeroes the duration in the tokens, so nothing extra is needed. The 4px press uses the same duration. The busy spinner keeps turning (--duration-spin) because it is a status.

Touch

Medium 40px + 4px lip, large 48px; small only inside larger tappable rows with 8px between neighbours.

Content

  • Verb first, sentence case: “Book 1:00–3:30 pm”, “Send reminder (3)”, “Use this plan”. Never “OK”, “Submit”, “Yes”.
  • Name the object when the context doesn’t: “Remove Ethan”, “Delete party”.
  • Show the count on bulk actions: “Send to 16 families”.
  • Keep it to about three words; it must fit at 360px.
