Tabs

Tabs switch between sections of the same thing: the parts of a party plan, or Themes / Venues / Fun & food.

Overview

Giddy uses navigation tabs (links with aria-current) because each tab is its own URL. Use APG tabs (role="tablist") only when panels swap without navigation.

Anatomy

  1. Current tabAccent label + 2px accent underline.
  2. TabMuted label, 44px tall.
  3. Rule1px default border.

Accessibility

Role and pattern

Navigation tabs: <nav aria-label> + links + aria-current="page". In-page tabs: APG Tabs, automatic activation.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
← →In-page tabs only: move and activate.

Focus

The shared ring (--focus-ring-width 2px of --color-focus-ring, 2px offset) appears on :focus-visible only.
