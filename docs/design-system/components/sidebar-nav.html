Sidebar navigation

The sidebar is the desktop map of Giddy: Plan a party, then Home, Ask Giddy and My parties, Explore, and You.

WCAG 2.2 AAStatus: stable

Overview

Visible from 1024px. Groups use overline headings. The bottom card shows the next party’s countdown and links to it, so the most important thing is one click away from anywhere.

  2. Primary CTA“Plan a party”, the one primary.
  3. Nav link44px pill; current = accent subtle.
  4. Group headingOverline.
  5. BadgeUnread count with meaning in aria-label.

Responsive behaviour

  • ≥ 1024px: sticky, full height.
  • < 1024px: hidden; the bottom nav takes over.

Theming

Surface background; current item uses --color-accent-subtle + --color-fg-accent.

Accessibility

Role and pattern

<nav aria-label="Primary"> with links; current link has aria-current="page".

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
EnterFollows the link.

Focus

The shared ring (--focus-ring-width 2px of --color-focus-ring, 2px offset) appears on :focus-visible only.

Labelling

Links are named by visible text; icons are hidden.

Motion

Colour and border changes use --duration-fast (120 ms) with --ease-standard; reduced motion zeroes the duration in the tokens, so nothing extra is needed.

Touch

44px rows (--target-comfortable).

  • Short nouns: “Home”, “My parties”, “Fun & food”.
