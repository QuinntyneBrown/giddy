Form field

A form field stacks a label, the control, help text and an error in a fixed order and spacing.

WCAG 2.2 AAStatus: stable

Overview

Every input, select and textarea sits in .field. Parts are 4px apart (--space-1); fields are 16px apart (--space-4).

Anatomy

  1. Label + optional markerRequired is the default; optional is marked.
  2. ControlAny input.
  3. HelpMuted hint.
  4. ErrorDanger text with ⚠, replaces nothing.

Variants

18 / 60
Plain and with counter.
HTML
<div class="field"><label class="field__label" for="ffv">First name</label><input class="input" id="ffv" value="Amara"></div><div class="field"><label class="field__label" for="ffv2">Headline</label><input class="input" id="ffv2" value="Zuri is turning 7!"><span class="field__counter">18 / 60</span></div>

Theming

Accessibility

Role and pattern

<label for> + aria-describedby listing help then error ids.
