Avatar

Avatars show people as round initials in a cheerful colour that stays the same everywhere they appear.

WCAG 2.2 AAStatus: stable

Overview

Every child and parent gets a pop colour (.pop--sky, --mint…) assigned once and reused, so Maya is always sky blue. Avatars next to a name are decorative.

Anatomy

  1. Circle--radius-full, pop background.
  2. InitialsTwo letters, pop foreground.
