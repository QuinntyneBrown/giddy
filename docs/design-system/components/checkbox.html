Checkbox

Checkboxes toggle independent options: “Keep me signed in”, “Send by text”, ticking a checklist task.

WCAG 2.2 AAStatus: stable

Overview

Use for options that don’t depend on each other, and for selecting rows. For a single setting that applies immediately use a switch. Groups sit in a <fieldset> with a <legend>.

Anatomy

  1. Box20px, --radius-xs, accent fill when checked.
  2. LabelClickable.
  3. DescriptionOptional muted line.

Variants

Group with legend.

Sizes

Not applicable: One size, 20px, inside a 24px target row.

States

VariantDefaultFocusCheckedDisabledInvalid
Checkbox

Responsive behaviour

  • Rows stack vertically; never more than 2 columns.

Theming

Checked fill --color-accent, tick --color-fg-on-accent.

Accessibility

Role and pattern

Native <input type="checkbox"> wrapped in its label.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
SpaceToggles.

Focus

The shared ring (--focus-ring-width 2px of --color-focus-ring, 2px offset) appears on :focus-visible only.

Labelling

Wrapping label; table row checkboxes get aria-label="Select Maya Chen".

Contrast

Box edge
Checked fill

Motion

Colour and border changes use --duration-fast (120 ms) with --ease-standard; reduced motion zeroes the duration in the tokens, so nothing extra is needed.

Touch

The whole label row is the target (≥ 24px).

Content

  • Positive phrasing: “Remind me the day before”, not “Don’t not remind me”.
