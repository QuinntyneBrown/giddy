Select

Selects pick one option from a list: sort order, search radius, who owns a task.

WCAG 2.2 AAStatus: stable

Overview

Use the native <select> for 4–15 options. Fewer than 4: use a radio group or choice cards so every option is visible. Changing a select never navigates by itself.

Anatomy

  1. LabelVisible.
  2. ControlNative select, custom chevron drawn with currentColor.

Variants

Inline label for toolbar sorts.
HTML
<label class="field" style="flex-direction: row; align-items: center; gap: var(--space-2);"><span class="field__label">Sort</span><select class="select input--sm" style="width: auto;"><option>Best match</option><option>Closest</option></select></label>

Sizes

Small in filter bars, medium in forms.
HTML
<select class="select input--sm" aria-label="Small"><option>Small</option></select><select class="select" aria-label="Medium"><option>Medium</option></select>
