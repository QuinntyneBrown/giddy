Textarea

Textareas hold longer words: the invitation message, notes for the venue, a note for Amara.

WCAG 2.2 AAStatus: stable

Overview

Use for anything that may run past one line. Show a counter when there is a limit (the invitation message is 280 characters). The chat composer is a borderless textarea inside its own container.

Anatomy

  1. LabelVisible.
  2. TextareaMin 2.5 control heights, resizes vertically.
  3. CounterRight-aligned caption, linked by aria-describedby.

Variants

Optional with no counter; auto-grows to 6 rows.
HTML
<div class="field" style="width: min(100%, 18rem);"><label class="field__label" for="tv1">Note for Amara <span class="optional">(optional)</span></label><textarea class="textarea" id="tv1" rows="2">Maya can’t wait!</textarea></div>

Sizes

Not applicable: One size; height follows rows (minimum 2).

States

VariantDefaultHoverFocusInvalidDisabledRead-only
Textarea

Responsive behaviour

  • Full width at every breakpoint.
  • Resizes vertically only.

Theming

Same tokens as text field.

Accessibility

Role and pattern

Native <textarea> with a label.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
EnterNew line (in the chat composer, Enter sends and Shift+Enter adds a line).

Focus

Same as text field.

Labelling

Counter is announced through aria-describedby; at the limit the counter turns danger and says “0 characters left”.

Contrast

Input text on surface
Input border on surface
Help text

Motion

Colour and border changes use --duration-fast (120 ms) with --ease-standard; reduced motion zeroes the duration in the tokens, so nothing extra is needed.

Touch

Full width; at least 2 lines tall.

Content

  • Pre-fill with a useful draft when Giddy can (the invitation message).
