Radio group

Radios pick one of a few options: deposit method, whether a parent stays, guest list source.

WCAG 2.2 AAStatus: stable

Overview

Use for 2–5 mutually exclusive options that benefit from descriptions. For picture-first choices (time of day, RSVP yes/no) use choice cards, which are radios underneath.

Anatomy

  1. LegendThe question.
  2. Radio20px circle, accent dot when checked.
  3. LabelThe answer.

Variants

Where’s the list?
With descriptions.
HTML
<fieldset><legend>Where’s the list?</legend><label class="choice"><input type="radio" name="vr" checked><span class="choice__text">Spreadsheet (.csv or .xlsx)<small>Columns: child, parent, email, mobile</small></span></label><label class="choice"><input type="radio" name="vr"><span class="choice__text">Zuri’s 6th: Mermaid Splash<small>Reuse 14 guests from last year</small></span></label></fieldset>

Accessibility

Role and pattern

Native radios in a <fieldset> with <legend>.

Keyboard

KeyAction
TabInto the group (to the checked radio).
↑ ↓ / ← →Moves and selects.

Focus

The shared ring (--focus-ring-width 2px of --color-focus-ring, 2px offset) appears on :focus-visible only.

Labelling

Legend is the question; each label is an answer.

Contrast

Edge
Checked

Motion

Colour and border changes use --duration-fast (120 ms) with --ease-standard; reduced motion zeroes the duration in the tokens, so nothing extra is needed.

Touch

Whole row is the target.

Content

  • Pre-select the safest common answer.
