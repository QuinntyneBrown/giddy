Link

Links go places. They are always underlined so they never rely on colour alone, and in Giddy they are grape to match the brand.

WCAG 2.2 AAStatus: stable

Overview

Use a link for navigation: “See all”, “Browse all 40 themes”, “Reset password”, tel: and mailto:. If it changes data, it’s a button. A link that looks like a button (“Open plan”) is still an <a>.

Anatomy

  1. Link textSays where it goes; makes sense on its own.
  2. Underline1px, offset 0.15em; never removed.

Responsive behaviour

  • Links wrap with their sentence; standalone links keep a 24px tall hit area.
  • Phone numbers are tel: links so they dial from the party-day run sheet.

Theming

Reads --color-fg-link and --color-fg-link-hover: grape-700/800 in light, grape-300/200 in dark.

Accessibility

Role and pattern

Native <a href>.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
EnterFollows the link.

Focus

The shared ring (--focus-ring-width 2px of --color-focus-ring, 2px offset) appears on :focus-visible only.

Labelling

Link text must make sense out of context (“Browse all 40 themes”, not “click here”). External links add visually hidden “(opens in a new tab)”.

Contrast

Link on canvas
Link on surface

Motion

None.

Touch

Standalone links sit in rows of at least 24px; inline links rely on the line height.

Content

  • Name the destination: “See all RSVPs”, “Terms & privacy”.
  • Don’t link whole sentences.
