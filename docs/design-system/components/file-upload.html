Overview

The real control is <input type="file">; the drop zone is an enhancement around it. After a file is chosen, show its name and size with a way to change it; while importing, show a determinate progress bar.

Anatomy

  1. Drop zoneDashed strong border, sunken well.
  2. PromptWhat to do.
  3. LimitsTypes and size.
