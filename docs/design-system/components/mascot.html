Component · Giddy

Mascot & logo

Giddy is a smiling grape balloon. The logo is the giddy wordmark (see Logo); the mascot shows moods: happy, party, sleepy and worried.

WCAG 2.2 AAStatus: stable

Overview

The mascot is inline SVG coloured by tokens, so it themes automatically. Drawn exactly as in the Magic Patterns “Giddy Brand Guidelines” (64 × 84 artwork; width follows height). Giddy has four moods, and each one has a job; never invent a fifth: happy for chat, greetings and the agent avatar; party (sun hat, open smile) for bookings confirmed, first run and invitations; sleepy (sky, eyes closed, two z’s) for empty states, no results and 404; worried (orange, raised brows) for errors, and only when something didn’t work. Unlabelled, each is named for its mood: “Giddy looking happy”, “Giddy looking ready to party”, “Giddy looking sleepy”, “Giddy looking worried”.
