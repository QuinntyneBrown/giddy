Layout primitives

Layout primitives place everything: a centred container, vertical stacks, wrapping clusters, card grids and the content-plus-aside split.

Overview

Pages compose .container → .page-header → .split (main + 22rem aside on desktop) → .stack/.grid-*. Columns, gutters and margins come from --layout-* tokens, which change at 768 and 1024px.

Anatomy

  1. .split mainFlexible column.
  2. Aside--layout-aside-width from 1024px; below it drops underneath.

Responsive behaviour

  • .grid-3: 1 → 2 (640px) → 3 (1024px).
  • .grid-2: 1 → 2 (768px).
  • .grid-4: auto-fill, min 9.5rem.
  • .split: stacked → content + aside (1024px).
  • .sidebar-layout: sidebar appears at 1024px.

Theming

Layout has no colour; wells use --color-bg-surface-sunken.

Accessibility

Role and pattern

DOM order equals visual order; the aside follows main content in the DOM.
