Start here

The Giddy design system is the visual and interaction language of the Giddy birthday planner: playful enough that kids light up, calm and clear enough that parents get things done. Everything here was extracted from the product mocks, normalised into tokens, and checked for WCAG 2.2 AA in light and dark themes.

How to use

<link rel="stylesheet" href="tokens/tokens.css">
<link rel="stylesheet" href="assets/components.css">

<button class="btn btn--primary" type="button">Plan a party</button>
  • Link tokens/tokens.css then assets/components.css (the Angular app imports both in styles).
  • Use the class names on each component page; force docs-only states with data-state.
  • Generate platform constants from tokens/tokens.json (DTCG).
  • Add data-theme="dark" on <html> to force dark; otherwise it follows the device.
  • Press t on any page here to toggle the theme.
