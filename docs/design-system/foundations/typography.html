Foundation

Typography

Rounded, friendly headings in heavy weights and a calm rounded body face, using system fonts so pages load instantly.

WCAG 2.2 AAStatus: stable
  • Overview
  • Roles
  • Scale
  • Usage
  • Accessibility
  • Tokens

Overview

Display and headings use --font-family-display at 700–800 for a toy-like warmth; body uses --font-family-sans. Both are rounded system stacks (SF Pro Rounded on Apple, Nunito when installed), so no web font is downloaded. Body stays 16px; nothing is smaller than 12px.

Usage

  • One <h1> per page; auth and dialog titles may use the h2 style on an h1 element.
  • Headings text-wrap: balance; paragraphs pretty; prose max --layout-measure.
  • Numbers in tables and stats use tabular figures.
  • Sentence case everywhere; overlines are the only uppercase.

Accessibility

  • All sizes in rem, so they follow the browser font size.
  • Line height 1.5 for body; text-spacing overrides (WCAG 1.4.12) don’t clip anything.
  • Weight is never the only signal of state.
