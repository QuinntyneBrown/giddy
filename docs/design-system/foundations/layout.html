Foundation

Layout

Mobile-first grid with 4/8/12 columns, a sidebar shell on desktop and a bottom tab bar on phones.

WCAG 2.2 AAStatus: stable
  • Overview
  • Breakpoints
  • Live grid
  • Page templates
  • Usage
  • Tokens

Overview

Base styles are for 360px. At 768px columns go to 8 with 24px gutters and 32px margins; at 1024px to 12 with 32px gutters and 48px margins, and the sidebar appears.

123456789101112

Resize the window: columns, gutters and margins follow the tokens.

Page templates

  • App shell: sidebar (≥ 1024px) + top bar + main + bottom nav (< 1024px).
  • Content + aside: .split with a 22rem aside.
  • Party pages: breadcrumb, header, party tabs, content.
  • Auth: centred 26rem card on confetti.
  • Wizard: 40rem column with a stepper.
  • Public: top bar, container, footer.

Usage

  • Use the layout primitives (layout) instead of new media queries.
  • Breakpoints are written in rem in media queries (custom properties can’t be used there).
