Foundation

Motion

Quick, springy and purposeful. Everything stops for reduced motion except status loops.

WCAG 2.2 AAStatus: stable
  • Overview
  • Durations and easings
  • Reduced motion
  • Usage
  • Tokens

Overview

Motion explains where things come from: sheets slide up, dialogs scale in, toasts rise, tiles lift. Hover is 120 ms, reveals 200 ms, dialogs 320 ms. Loops (spinner, shimmer, typing dots) have their own tokens.

Durations and easings

Reduced motion

Under prefers-reduced-motion the tokens set durations to 0.01 ms and components drop animations; skeleton shimmer and indeterminate bars become static. The spinner keeps one slow turn because it reports status.

Usage

  • Never animate on page load except skeleton shimmer.
  • Nothing over 500 ms except loops and progress.
  • Spring easing only for playful lifts (quick-action tiles).
