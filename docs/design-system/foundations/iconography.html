Iconography

Rounded 2px line icons that inherit colour, plus emoji art and Giddy the mascot for illustration.

WCAG 2.2 AAStatus: stable
  • Overview
  • Icon set
  • Sizes
  • Labelling
  • Tokens

Overview

Icons are inline SVG on a 24-unit grid, 2px round strokes, currentColor. Emoji provide the colourful art on tiles, choice cards and invitations; they are always aria-hidden next to words. Giddy is the only illustration.

Labelling

  • Decorative icons: aria-hidden="true".
  • Icon-only buttons: aria-label on the button.
  • Meaningful standalone icons: role="img" + aria-label.
  • Emoji never carry meaning alone.
