Overview

Overlays interrupt; use them sparingly.

When to use

NeedUse
Short task needing page contextDialog
Destructive confirmationDanger dialog; typed name for big losses
Agent action needing approvalConfirmation dialog listing changes (Use this plan)
A few item actionsMenu
Long flowA page
Result noticeToast

Structure

States

StateBehaviour
defaultFocus first field / safe button
busyNo double submit; Cancel disabled
invalidInline errors
failedAlert at top, inputs kept
successNext step, one button

Responsive

  • Sheet under 640px; centred above.
  • Footer sticky while body scrolls.
  • Page scroll locked.

Accessibility

  • APG modal dialog; page inert; Esc closes; focus returns.
  • Never stack dialogs.

Content

  • Questions for confirmations; tasks otherwise.
  • List consequences.
