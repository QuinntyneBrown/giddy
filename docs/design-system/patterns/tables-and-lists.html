Data tables & lists

Tables for comparing, lists for reading, tiles for browsing.

Overview

Giddy has three collection shapes: tables (guests, budget, compare), lists (nudges, bookings, notifications) and tile grids (themes, venues, vendors).

When to use

ContentUse
Compare across columnsTable
Read top to bottomList
Browse visuallyTile grid
Selection + bulk actionTable with checkboxes + bulk bar

Responsive

  • Tables scroll in their frame on phones.
  • Tile grids 1 → 2 → 3 columns.
  • Pagination over 50 items.

Accessibility

  • Captions, scope, aria-sort.
  • Row action names include the item.

Content

  • Filter chips show counts: “Waiting 3”.
