Pattern

Empty & error states

Never a dead end: explain, reassure, and offer the next step, with Giddy’s mood setting the tone.

Overview

Empty and error states are moments of truth. They use the empty state and error page components.

When to use

KindMascotAction
First runParty hatCreate the first thing
Filtered emptySleepyRelax a named filter
PermissionWorriedWho to ask / switch account
Load errorWorriedTry again + way back + reference
Not yet (wrap-up before party)IconExplain when it opens

Structure

No venues under $250 with a nut-free kitchen

Raising the max price to $350 shows 3 venues.

Filtered empty with a concrete fix.

States

Page stateTreatment
emptyExplain + one action
no-resultsFilters stay visible; suggest a change
errorChrome stays; Try again; reference id
partialOnly the failed section shows an alert

Responsive

  • Centred; actions wrap; mascot shrinks on phones.

Accessibility

  • Errors are role=alert; empty states are labelled sections.
  • Mascot labelled or hidden.

Content

  • Formula: what + why + action.
  • Name the filters that caused no results.
