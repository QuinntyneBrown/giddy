Overview

The app shell is a sidebar on desktop and a bottom tab bar on phones, with a sticky top bar. Party pages add a breadcrumb, a page header and party tabs.

When to use

NeedUse
Top-level destinationsSidebar / bottom nav
Sections of one partyParty tabs (links)
Way back upBreadcrumb
Steps in a flowStepper
AgentAsk Giddy in nav centre and sidebar

Responsive

  • Sidebar ≥ 1024px; bottom nav below.
  • Page-header actions move under the title on phones.

Accessibility

  • Landmarks: header, nav (labelled), main, footer.
  • Skip link first.
  • Same order on every page.

Content
